## Round-to-nearest-even evidence boundary

`LowerTileToISA.cpp` only folds when the body is the precise divide/multiply/`math.roundeven`/clamp form. The upstream Gemmini default config in [ucb-bar/gemmini `Configs.scala`](https://github.com/ucb-bar/gemmini/blob/master/src/main/scala/gemmini/Configs.scala#L1117-L1173) defines accumulator scaling with HardFloat `round_near_even` for conversion, multiply, and conversion back to integer, with saturation. This agrees with the compiler's matched `roundeven` operation. That public `master` source is corroborating Gemmini semantics, not proof of the exact checked-out bitstream revision; local Chipyard's Gemmini submodule sources were absent. The model's own assembly independently proves the current bucket uses scalar tie-aware rounding because the Gemmini epilogue did not replace it.
